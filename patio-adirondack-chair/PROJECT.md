# Patio Adirondack Chair

Parametric Adirondack chair for a covered patio. Tall front legs double as arm supports; long back legs frame the reclined slatted back.

## Dimensions

| Property | Value |
|----------|-------|
| Width | 28" |
| Depth | 32" |
| Seat height | 14" |
| Arm height | 25" |
| Back height | 40" (to top of back legs) |
| Back angle | 20° from vertical |

## Design

- **Front legs**: 2×4, floor to arm height (25"); serve as arm supports
- **Back legs**: 2×4, floor to back top (40"); frame the sides of the reclined back
- **Arms**: 2×4 flat, run full depth plus 4" overhang in front
- **Seat**: 5 × 1×4 slats on front/rear 2×4 rails
- **Back**: 4 × 1×4 slats with top and bottom 2×4 rails, angled 20° back

- All dimensions are actual lumber sizes (not nominal)
